# D-I-S-APP-

**ART EYE ●** — *Your eye on the art world.*

The app lives in [`art-eye/`](art-eye/): a React Native + Expo iOS app that gathers
Sydney's museum and gallery exhibitions into one editorial agenda, with a personal
seen/want-to-see record, venue submissions, and admin moderation, backed by Supabase.

See [`art-eye/README.md`](art-eye/README.md) for run instructions, the Supabase setup, and
the design system.
